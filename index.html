ยังไม่ได้เชื่อมต่อปฏิทิน

เชื่อมต่อบัญชี Google Calendar เพื่อดึงตารางนัดมาสรุป ข้อมูลจะถูกดึงเฉพาะแบบอ่านอย่างเดียว (read-only)

ตั้งค่าการเชื่อมต่อ

แอปนี้ทำงานฝั่งเบราว์เซอร์ทั้งหมด ไม่มีเซิร์ฟเวอร์กลาง ต้องสร้าง OAuth Client ID ของตัวเองจาก Google Cloud Console เพื่อขออนุญาตอ่านปฏิทิน
สร้างได้ที่ Google Cloud Console → Credentials เลือก "OAuth client ID" ประเภท Web application แล้วเพิ่มโดเมนที่ใช้เปิดหน้านี้ใน "Authorized JavaScript origins" (เช่น ที่อยู่ GitHub Pages ของพี่) และเปิดใช้งาน Google Calendar API ในโปรเจกต์เดียวกัน
